## Kaam #1: Qodo PR Review (Mac Mini track ke liye)

### Qodo kya hai?
Qodo ek **AI code reviewer** hai. Aapka code GitHub par hai, Qodo usay
automatically check karta hai aur "ye line theek hai / ye bug hai" batata hai.
Hackathon judges ko dikhta hai ke aapne apna code quality ke saath likha.

### Steps (bilkul asaan):
1. **Website kholo:** https://www.qodo.ai/  → "Sign up" karo (GitHub se login).
2. **GitHub connect karo:** Qodo ko apne GitHub account se link karo aur
   "Install Qodo on your repository" dabao → `malik-saab-c/clarity-agent-hackathon` select karo.
3. **Ek change karo (dummy bhi chalega):** GitHub website par jao →
   apne repo mein koi bhi file kholo (jaise README.md) → ✏️ edit icon dabao →
   koi chota sa sentence add karo → "Commit changes" dabao.
   (Ye ek PR banata hai — Qodo automatically usay review karta hai.)
4. **Screenshot lo:** Qodo ka review dikhta hai → screenshot save karo.
5. **Is screenshot ko submission notes mein laga do.**

> Bas! Aapka "Best Code Quality" track ka evidence ready. Koi coding nahi chahiye.
